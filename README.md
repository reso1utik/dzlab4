# Домашнее задание к работе 4

## Условие задачи

Три груза (A, B, C кг) можно погрузить в контейнер, если вес каждого из них кратен пяти. Запишите условие, при котором диспетчерская система дает разрешение на погрузку.

## 1. Алгоритм и блок-схема
### Алгоритм решения
1. **Начало**
2. Задать исходные данные: 
   - m (Вес каждого контейнера)
3. Выполнить проверку кратности 5:
   - m%5 == 0 то вывести провести погрузку разрешаю(выполнить для каждого элемента одновременно)
   - m%5 != 0 то вывести провести погрузку запрещаю
4. **Конец**
